# Free scope and family setup

The listed path is free to read or use, not necessarily every product from the same organisation. Devices, internet, printing and optional physical materials are separate. Trials and paid AI tutoring are not included as free maths courses.

| Resource type | Check before starting |
|---|---|
| Public lessons and tasks | Choose an appropriate reading level and a task the child can explain |
| Visual tools | Browser compatibility, how to keep a copy, and whether saving requires an account |
| Apps | Supported device, parent setup and the current store listing |
| Videos | Region, device, subtitles and any sign-in route |
| Free web games | Advertising, third-party links and whether a paid mobile app is separate |
| International curricula | Match the actual topic with the school; do not copy US/UK grade labels into Australian year levels |

Khan Academy’s core maths is the listed free path; Khanmigo is not included. Topmarks web games are separate from paid apps. Math is Fun carries advertising. GeoGebra’s listed path is non-commercial study use; commercial reuse has different terms. PhET web simulations are separate from offline/app offers or teacher extras.

Use a parent/teacher-supported setup when an account is required. No child account, upload, payment or subscription was created for this directory. Free access does not mean copying an entire worksheet pack into another product is allowed.
