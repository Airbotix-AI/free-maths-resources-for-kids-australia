## Choose by age and year

Age/year links and topic order are editorial starting points, not entry-age rules or a certified curriculum map. State cut-offs, readiness and school courses vary. US Grade and UK Key Stage are not automatic Australian equivalents. Foundation has different local names. Years 11–12 depend on the actual subject and state syllabus.

## How to use this list

This edition is in English. External resources have their own language support; translating this guide does not translate their lessons. International resources are selected by topic, not assumed Australian curriculum alignment.

Official sources support the access notes. No child accounts, paid subscriptions, full courses or every interactive were tested. Start with one model, an explanation and a check.
